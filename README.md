# SQL Projects

A collection of SQL data analytics projects focused on business analysis, sales analytics, customer behavior, operational analysis, revenue analysis, transaction analysis, ride analytics and advanced SQL querying.

## Projects

### 1. Coffee Shop Sales Analysis

Coffee shop sales analytics project analyzing monthly sales, month-over-month sales changes, order volume, quantity sold and monthly performance using transaction-level data.

**Tools:** MySQL, SQL, Window Functions, Aggregate Functions, Date Functions

[View Project](<./Coffee Shop Sales Analysis>)

---

### 2. Domino's Pizza Sales Analysis

Pizza sales analytics project analyzing total orders, revenue, pizza pricing, pizza sizes, top-selling pizzas, pizza categories, hourly order distribution and revenue contribution.

**Tools:** MySQL, SQL, Joins, Aggregate Functions, Window Functions, Subqueries

[View Project](<./Domino's Pizza Sales Analysis>)

---

### 3. Indian Election Results Analysis

Election data analysis project analyzing total parliamentary seats, state-wise seat distribution, party and alliance-wise results, EVM versus postal votes, constituency-level results and candidate vote performance.

**Tools:** MySQL, SQL, Joins, CASE Statements, Aggregate Functions, Subqueries, Data Transformation

[View Project](<./Indian Election Results Analysis>)

---

### 4. Music Store Data Analysis

Music store analytics project analyzing customer spending, invoices, artists, albums, tracks, genres, rock music listeners, country-wise purchasing behavior and customer spending patterns.

**Tools:** MySQL, SQL, Joins, CTEs, Subqueries, Aggregate Functions

[View Project](<./Music Store Data Analysis>)

---

### 4. Ola Ride Analytics

Ride-hailing analytics project analyzing successful bookings, ride distance, vehicle performance, customer booking behavior, cancellations, driver ratings, customer ratings, payment methods, incomplete rides and booking value.

**Tools:** MySQL, SQL, Aggregate Functions, Filtering, Grouping, Sorting

[View Project](<./Ola Ride Analysis>)
